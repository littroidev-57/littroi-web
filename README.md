# Littroi — Attention Engineering & Brand Media Agency (MERN Stack)

Modern high-performance web application and content management system for **Littroi Media**. Built with React 19, Tailwind CSS, Framer Motion, Express.js, MongoDB, and Cloudinary.

---

## 🚀 Features

- **Dynamic Homepage Showcases**:
  - Our Projects (16:9 Landscape Video Showcase with smooth navigation)
  - SaaS Video Showcase (16:9 Showcase slider with Next/Prev controls)
  - Podcast Clips (9:16 Vertical Video Reels)
  - Short Form Content (9:16 Vertical Video Reels)
- **Deep-Dive Case Studies**:
  - Full statistical breakdown, dynamic tags, client metrics, and multi-screenshot viewer.
- **Blog & Insights**:
  - Real-time search, category filtering, sorting (Latest, Oldest, A–Z), hero featured post, and dynamic child post view (`/blog/:slug`).
- **Careers & Studio Positions**:
  - Interactive job listings and application handling.
- **Full Admin Control Panel (`/admin`)**:
  - Live CRUD for Case Studies, Home Videos, Blog Articles, Careers, and Leads Inbox with two-step modal deletion confirmations and direct Cloudinary media uploads.

---

## 🛠️ Tech Stack

- **Frontend**: React 19, Vite, Tailwind CSS, Framer Motion, Lucide React
- **Backend**: Node.js, Express.js, MongoDB (Mongoose), Cloudinary API, Multer
- **Deployment & Optimization**: RESTful API, Helmet, Rate-limiting, CORS, SEO meta tags

---

## 💻 Quick Start

### 1. Backend Setup
```bash
cd littroi-mern/server
npm install
npm run dev
```

### 2. Frontend Setup
```bash
cd littroi-mern/client
npm install
npm run dev
```
